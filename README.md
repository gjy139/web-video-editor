# 🎬 OpenCut Studio - 100% 무료 웹 동영상 & CG/VFX 편집기

> **OpenCut**은 브라우저에서 실행되는 100% 무료, 워터마크 없는 강력한 웹 동영상 및 CG/VFX 편집 프로그램입니다.  
> 별도의 유료 구독이나 회원가입 없이 브라우저 자체 컴퓨팅 파워로 영상을 자르고, 자막을 입히고, **크로마키(그린스크린)** 및 **VFX 파티클 특수효과**를 합성하여 고화질 영상으로 내보낼 수 있습니다.

---

## 🌟 주요 핵심 기능

### 1. 🛸 CG (컴퓨터 그래픽스) & 크로마키 합성 엔진
- **그린스크린/블루스크린 크로마키 (Chroma Key)**:
  - 초록색 또는 파란색 배경을 투명하게 실시간 제거
  - 색상 민감도(Similarity) 및 가장자리 페더링(Smoothness) 미세 조절
- **오브젝트 변형 (Transform)**:
  - 크기 확대/축소 (Scale: 20% ~ 250%)
  - 자유로운 각도 회전 (Rotation: -180° ~ 180°)
  - 가로(X), 세로(Y) 위치 이동
- **합성 블렌드 모드 (Blend Mode)**:
  - 일반 (Normal), 스크린 (Screen - 검은 배경 제거), 더하기 (Add / Lighter - 발광), 곱하기 (Multiply), 오버레이 (Overlay), 반전 (Difference)
- **카메라 모션 애니메이션**:
  - 💥 타격감 카메라 쉐이크 (Shake)
  - 💓 펄스 비트 (Pulse)
  - 🎈 둥둥 부유 효과 (Float)
  - 🔄 무한 회전 (Spin)

### 2. 💥 실시간 VFX 파티클 & 오버레이
- 🔥 **화염 불티 파티클 (Ember & Fire Sparks)**: 화면을 채우는 생생한 불씨 파티클
- ⚡ **사이버 글리치 (Cyberpunk Glitch & RGB Split)**: 색수차 및 수평 지터 슬라이스
- ❄️ **시네마틱 스노우 (Cinematic Snow)**: 흩날리는 눈송이
- 🌧️ **감성 빗줄기 (Rain Stream)**: 비 내리는 텍스처
- ☀️ **아나모픽 빛 번짐 (Light Leak / Lens Flare)**: 영화적인 웜톤 플레어
- 🌐 **사이버 레이저 그리드 (Perspective Grid)**: 80년대 레트로 신스웨이브 그리드

### 3. 4단 멀티트랙 시퀀서 타임라인
- **자막 / 텍스트 트랙**: 타이틀 및 자막 배치
- **🛸 CG / 오버레이 트랙**: 크로마키 클립 및 CG 합성 레이어
- **🎬 메인 비디오 트랙**: 기본 영상 컷 편집
- **🎵 오디오 / BGM 트랙**: 배경음악 및 효과음
- 클립 양 끝 드래그로 **트림(Trimming)** 및 <kbd>S</kbd> 키로 **즉시 분할(Split)**

### 4. 고화질 실시간 캔버스 프리뷰 (Live Compositor)
- 30 FPS 프레임 레이트 실시간 렌더링
- 화면 비율 원클릭 전환:
  - `16:9` 유튜브 / 일반 영상 (1920 × 1080)
  - `9:16` 유튜브 쇼츠 / 인스타 릴스 / 틱톡 (1080 × 1920)
  - `1:1` 정사각 피드 (1080 × 1080)
  - `4:3` 클래식 비디오 (1440 × 1080)
- 프레임 단위 탐색 (`←`, `→` 키) 및 5초 점프 이동

### 5. 스타일 자막 & 타이틀 엔진
- 유튜브 하이라이트 (노란 볼드 + 블랙 외곽선)
- 넷플릭스 박스 (블랙 반투명 박스)
- 사이버 네온 (네온 발광 효과)
- 임팩트 밈 스타일 (볼드 외곽선)

### 6. 즉석 CG & 비디오 생성기
- 🟢 **크로마키 3D 사이버 오브젝트 데모 클립 생성** (초록 배경에 회전하는 에너지 링 & 발광 코어)
- 🌆 레트로 신스웨이브 클립
- ⏱️ 카운트다운 타이머 클립
- 🎵 Web Audio API 기반 오프라인 Lo-Fi BGM 합성

### 7. 100% 무료 브라우저 렌더링 & 내보내기 (Export)
- 클라이언트 측 Canvas + MediaRecorder 기반 고화질 WebM/MP4 비디오 다운로드
- 워터마크 없음, 화질 제한 없음, 100% 개인정보 보호

## ⌨️ 단축키 안내

| 단축키 | 기능 |
|--------|------|
| <kbd>Space</kbd> | 재생 / 일시정지 |
| <kbd>S</kbd> | 현재 위치에서 클립 자르기 (분할) |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 선택한 클립 삭제 |
| <kbd>←</kbd> / <kbd>→</kbd> | 1프레임 이전 / 다음으로 이동 |
| <kbd>Shift</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | 1초 뒤로 / 앞으로 이동 |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | 실행 취소 (Undo) |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> / <kbd>Ctrl+Shift+Z</kbd> | 다시 실행 (Redo) |

## 🚀 실행 방법

### 방법 1: 원클릭 실행 (Windows)
`start.bat` 파일을 더블 클릭하면 개발 서버가 켜지고 브라우저(`http://localhost:5173`)가 자동으로 열립니다.

### 방법 2: 터미널 명령
```bash
cd web-video-editor
npm run dev
```
